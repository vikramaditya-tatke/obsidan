# My Journey

- Making the Data Engineering processes as efficient as possible - I believe thinking about efficiency of the processes allows us to achieve two objectives - 
	1. **Reducing the budget** - If the changes implemented are well propagated and align properly with the business, this ultimately translates to reduced fees for the customer
	2. **Sustainability** - Data Engineering workloads are extremely computationally demanding. As we step into the age of LLMs it is very important to measure our impact on the environment and as DEs we can choose to use technologies that are most efficient for the given task. Considering the trade-offs between faster processing times using familiar tools or consciously deciding to write slightly complex code / using newer and better tools to manage the same workloads within lower compute boundaries is essential for the long-term.
