**3. Can you describe a data pipeline you’ve designed or maintained and the technologies involved?**
I single-handedly designed and built a robust, fault-tolerant, high-volume, end-to-end data pipeline using Python that collects terabytes of data every week over REST APIs from multiple instances of the same application deployed across different cloud and on-premises platforms and ingests into ClickHouse Cloud. This pipeline was initially written in pure python using multi-processing and multi-threading utilizing solid logging infrastructure. I eventually created a Python library of the modules used in the pipeline and then migrated it into Apache Airflow DAGs using Task Groups and Dynamic Task Mapping to retain the concurrent and parallel processing. The pipeline itself generates millions of logs and writes them to ClickHouse Cloud for further analysis. I ensured logs sent to ClickHouse are buffered within the logging module within the pipeline before insertion. I used the Polars and Pydantic library to handle data validation and transformation. I used "ijson" library for streaming huge API responses efficiently and the "orjson" library for parsing the JSON response. Data lands into a staging area within ClickHouse after which "Incremental Materialized Views" are created to pre-aggregate the data and prepare it for BI. I created dashboards on the logs generated by the pipeline to monitor and alert on various metrics essential to the downstream consumers and the stakeholders of the upstream system.
