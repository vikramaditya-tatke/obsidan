## Managed Service for Apache Flink
### Active Recall
- What specific problem does this service solve in a data pipeline?
- How does this integrate with S3 or IAM?

---

Managed Service for Apache Flink was formerly known as Kinesis Data Analytics.

It is used to process real-time streaming data. This services uses SQL for data processing. It generates an output stream by applying the data processing logic described using SQL.

- Creates in-application streams.
- Can read from reference data.
